# 에피소드 리더 (PWA)

구글 드라이브 폴더의 마크다운(.md) 파일을 읽는 개인용 설치형 웹앱입니다.
서버 없이 브라우저가 구글 드라이브 API와 직접 통신하며, 드라이브의 파일을 지우거나 휴지통으로 보내지 않습니다.

## 설정

1. Google Cloud 콘솔에서 Google Drive API를 켭니다.
2. OAuth 동의 화면을 만들고 범위 `https://www.googleapis.com/auth/drive`를 추가합니다.
3. 웹 애플리케이션 유형의 OAuth 클라이언트 ID를 만들고, 승인된 JavaScript 원본에 앱 주소의 origin을 넣습니다.
4. 클라이언트 ID를 `config.js`에 넣습니다.

## 기능

- 목록, 마크다운 본문, 이전/다음, 이어 읽기
- 보기 설정: 글꼴(직접 추가 가능), 크기, 간격, 여백, 정렬, 테마
- 스크롤 / 쪽 넘기기, 넓은 화면에서 양쪽 보기
- 오프라인 저장본
